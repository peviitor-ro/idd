# Server TEST — Raspberry Pi 4

## Hardware

| Component | Detalii |
|-----------|---------|
| **Model** | Raspberry Pi 4 (ARM Cortex-A72, 4 cores) |
| **RAM** | 8 GB (7.6 GiB usable) |
| **Swap** | 4 GiB swap |
| **Stocare** | microSD 64 GB (58 GB utilizabili, ~41 GB liberi) |
| **Arhitectură** | aarch64 |
| **Rețea** | Ethernet 1000 Mbps (eth0: 192.168.1.142/24) |

## Software

| Component | Detalii |
|-----------|---------|
| **OS** | Debian 13 (Trixie), kernel 6.18.39+rpt-rpi-v8 (aarch64) |
| **Hostname** | pi4 |
| **Web Server** | Apache HTTP Server (php:8.2-apache, container `peviitor-api`) — port extern 8081, servește frontend + API |
| **TLS** | Terminat la edge (Nginx Proxy Manager pe RPi API — Let's Encrypt) |

## Rețea

| Detaliu | Valoare |
|---------|---------|
| **IP Local** | 192.168.1.142/24 |
| **IP Public** | 86.122.35.88 (prin NAT, port forwarding) |
| **Hostname DNS inversat** | 86-122-35-88.rdsnet.ro |
| **Acces extern** | Traficul intră prin router → Nginx Proxy Manager (RPi API, 192.168.1.135) → RPi TEST. `test.peviitor.ro` → `192.168.1.142:8081` (Apache), `testsolr.peviitor.ro` → `192.168.1.142:8983` (SOLR) |

## Docker Containers

| Nume | Imagine | Porturi | Rol |
|------|---------|---------|-----|
| peviitor-api | Apache PHP 8.2 | 8081 → 80 | API BFF test |
| peviitor-solr | Solr 10.0.0 | 8983 → 8983 | SOLR test |

## Servicii

- **Docker Engine** — activ
- **Apache PHP 8.2 (peviitor-api)** — frontend + API (port 8081)
- **SOLR (peviitor-solr)** — index test (port 8983)
- **Raspberry Pi Connect** — wayvnc (acces remote)

- React SPA (search-engine, build mode `qa`)

## API

- PHP BFF v0/v1 + Swagger UI

- Accesibil la https://testsolr.peviitor.ro
